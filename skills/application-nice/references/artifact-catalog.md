# Application artifact catalog

| Stage | Minimum useful output | Optional expansion |
|---|---|---|
| Opportunity triage | fit verdict + five decisive signals | company snapshot |
| Recruiter response | short message + current CV | one-page evidence note |
| Formal application | targeted CV + cover note | selected portfolio |
| Search-firm interview | narrative + success-profile matrix | board-gate risk sheet |
| Hiring-manager interview | evidence stories + questions | company and organization brief |
| Final round | appointment thesis + first-90-day hypothesis | application pack, 5–7 pages |

Use `$nice-output-engine` templates:

- `executive-brief` for one- or two-page fit and decision notes;
- `benchmark-matrix` for role, archetype, or opportunity comparisons;
- `application-pack` for two- to seven-page interview and final-round packs.

Do not generate every artifact by default. Preserve the original CV and name variants with persona, company, role, language, and date.
