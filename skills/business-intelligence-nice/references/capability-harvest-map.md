# Capability harvest map

This skill consolidates methods from eight source skills without reproducing their artifact-specific routing.

| Source capability | Reused method | Boundary retained |
|---|---|---|
| `corporate-ai-strategy-intelligence` | priority → driver → capability → AI role → evidence → gap | strategy is not a list of use cases |
| `tech-leadership-org-intelligence` | legal structure, current roles, decision rights, RACI and influence with confidence | titles and inferred reporting lines remain hypotheses |
| `ai-hiring-workspace-intelligence` | dated, deduplicated hiring corpus and capability inference | hiring is not deployed capability |
| `ai-newsflow-sourcing-intelligence` | announcement, launch, production and result chronology | partnership is not execution |
| `enterprise-demand-intelligence` | product-agnostic desired state minus current capability | demand stays separate from offer truth |
| `product-icp-intelligence` | problem, anti-problem, ICP, anti-ICP, evidence, gates and alternatives | offer truth stays independent of named accounts |
| `opportunity-fit-matching` | gates before scores, sensitivity, falsifier and decision policy | no fresh research during matching |
| `engagement-pilot-design` | smallest representative proof, baseline, guardrails and stop criteria | pilot design cannot repair an invalid fit |

For a focused request, load only the relevant rows. For a complete diagnostic, execute corporate, organization, hiring, and newsflow before enterprise demand; define offer truth independently; cross them only in the fit stage; design proof last.
