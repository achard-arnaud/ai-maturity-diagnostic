# Source map — prospection-principes

## Source primaire (~80%)

Eliott Meunier — *Comment prospecter avec l'IA ? / Prospection amplifiée par IA*.
Transcript YouTube auto-généré fourni manuellement par l'utilisateur, complété par captures du support Obsidian.

Principes repris :
- ICP comportemental ;
- douleurs en couches + désir + verbatim ;
- 5 niveaux de conscience ;
- nids à prospects = densité + contexte commun ;
- privilégier signaux d'intention ;
- scraper/acquérir puis enrichir ;
- scorer avant enrichissement coûteux ;
- grille /100 ;
- base de données pilotée par statuts ;
- réaction → piédestal → problème → demande ;
- partage de solution, pas pitch ;
- relances à valeur ajoutée ;
- J+1 / J+4 / J+10 comme séquence de référence du support ;
- process-first, l'IA exécute la fiche process.
