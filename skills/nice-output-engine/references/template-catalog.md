# Template catalog

| Template | Pages | Orientation | Best use |
|---|---:|---|---|
| `executive-brief` | 1–2 | Landscape | Decision, vendor, company, pilot or due-diligence brief |
| `benchmark-matrix` | 2–4 | Landscape | Comparable options, criteria, evidence and implications |
| `business-note` | 5–7 | Portrait | Executive question, evidence, analysis, options, recommendation and actions |
| `application-pack` | 2–7 | Portrait | Opportunity, company, fit, narrative, evidence and interview preparation |

Add a template only if none of these can preserve the requested reading sequence. Register it in `templates/manifest.json`, keep business rules upstream, create one representative example, and validate both page count and visual constraints.
