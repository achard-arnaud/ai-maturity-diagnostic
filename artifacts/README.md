# Artefacts de recherche

Ce dossier contient les gabarits canoniques. Pour une mission, les copier dans `studies/<entreprise>-<date>/artifacts/` ; ne pas écrire les résultats d’une entreprise directement dans les modèles.

Le parcours et les responsabilités sont définis dans [ARTIFACT_REGISTRY.md](ARTIFACT_REGISTRY.md).

## Règles communes

- Centraliser sources et propositions dans `01b_evidence_ledger.md`.
- Citer les `Claim ID` dans les tableaux et conclusions aval.
- Séparer fait, inférence, hypothèse et inconnue.
- Noter portée, dates, confiance, contre-preuves et limites.
- Distinguer annonce, lancement, production, réplication et échelle.
- Utiliser `Non établi` plutôt que d’inventer.
- Ne pas effacer une contradiction lors de la synthèse.

## Parcours

`00 → 01 → 01b → 02 → 03/03b/03c → 04 → 05 → 06 → 07 → 08`

Les utilitaires GitHub présents dans ce dossier servent au benchmark du framework ; ils ne constituent jamais une preuve sur l’entreprise étudiée sans lien direct et daté.
